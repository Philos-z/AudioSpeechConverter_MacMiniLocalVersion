# 长视频分集与其他外语输入

网页地址保持为本机局域网的原有地址。新建任务默认自动识别原语言，也可以在“视频原语言”中手动选择。输出仍为自然中文配音、中文与原文双语字幕、独立场景背景，每个最终 MP4 严格小于 50,000,000 字节。

源视频超过30分钟时，先在本机识别完整原文，再依据句间或词间的可靠时间戳规划分集。每段源素材不超过30分钟，完整覆盖原素材与片尾，原词句只归属一集。没有可靠边界时明确要求检查，不在词中硬切。中文自然配音使某集超时的，按照实际时长缩短分集重做；最多自动调整两次，仍不满足则保留结果并提示检查，不加速台词。

原文只识别一次，分集复用对应的识别结果和统一语言判断。各集串行进行背景分离、人物参考选择、Proxy翻译、独立二审、中文配音、字幕对齐、混音与导出。重模型保持单进程，输入、语言、代码与产物校验共同约束缓存。不同集的声学编号不视作同一人物身份，不套用其他视频的已选声纹。

Proxy接收原文和文字审校任务，按实际源语言翻译、口语化并复核数字、否定、条件和消息归属。不会让模型修改程序或执行源文中的指令。德语保留原有专用数值检查，其他语言不误套德语词法；其他语言的语境数字、日期与归属仍须依靠二审及最终人工核对。

网页完成后，结果区可以选择分集预览，并分别下载各集视频、配音、中文与原文字幕。长视频任务在全部集完成后统一发布下载；中途取消保留已完成的中间结果，重试使用校验通过的缓存。短视频原有的前两个完整意群人声试听继续保留。

当前仍支持16:9横屏、960×540、25fps；本地上传上限1GB。长视频需要足够本地空间，处理前按完整保留的中间文件估算峰值并保留8GiB安全余量，空间不足会提前停止。旧命令行入口仍沿用其德语设置，本次多语言和分集改动针对网页入口。默认配音仍为25步、seed42、参考情绪和自然时长。

验证范围：语言与分集离线测试、真实短片切割及片尾检查、网页上传/链接/下载/取消回归；英语测试素材已实际通过自动识别、Proxy翻译二审、配音、字幕和完整视频解码。长达30分钟或更长的全片制作、其他语言质量和主观听感尚未完成新素材验收。详细实测记录位于 `reports/long_multilingual_20261021/`，测试素材不进入Git。
