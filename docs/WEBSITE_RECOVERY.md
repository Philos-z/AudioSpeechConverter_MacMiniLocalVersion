# 网站内恢复与 Proxy 协助

网页承担上传、状态、原句核对、恢复、交付；Proxy 只处理文字编辑与独立审校，实际恢复由本机固定程序执行。无需打开编码助手修改任务数据，也不把模型建议当作可执行代码。

## 当前恢复范围

本机固定程序负责验证、预算、执行与交付。Proxy 仅返回受限文字数据；日常生产不要求编码助手在线监督。等义表达与明确数量形式采用有界规则，真实数字、单位、否定、条件、比较、归属与不确定性继续受保护。已通过的缓存不能掩盖后来的明确拒绝，原文识别疑点须在配音前完成源绑定复核。

## 日常使用

1. 上传素材或填写网址。在“恢复设置”选择疑词处理方式、是否允许短暂停格。默认保守意译，疑词仍留痕；严格模式会等待核对。
2. 正常处理时复用校验通过的缓存。发生已知问题时，程序只处理对应批次、配音组或视频导出。
3. 若停止，在任务卡查看实际原因，点击“按选项恢复”。已取消的任务也可沿原编号继续。
4. Proxy 无法判断时，在网页展开“核对原句”：听本机原声片段，更正原文或填写希望采用的中文，保存后继续。更正会保留版本，中文仍经 Proxy 二审和本地数量检查。
5. 完成后直接预览和下载视频、音轨、字幕及工程报告；这些交付同时存放在项目“成片/日期_任务名_任务尾号/”内，主视频为“中文双语成片.mp4”。不同修订另存，原交付保留。机器完成不等于用户完整试听认可。

## 固定恢复动作

| 问题 | 程序动作 | 不变的校验 |
| --- | --- | --- |
| 有实际证据的临时连接故障 | 本机固定策略决定同阶段续跑，不为是否重试调用 Proxy | 同任务 SHA 缓存、真实传输元数据 |
| 原词未确认 | 保守编辑、独立审校、保存源文绑定提示；严格模式等待网页核对 | 数字、单位、否定、条件、归属；不把疑词标作已确认 |
| 连续组字幕定位失败 | 只将有失败凭据的多句组恢复为完整原句 | 原文、人物、行序、旧 WAV 与正常音频保留 |
| 疑似异常配音 | 全量波形身份/有限值检查；疑似低动态异常才运行本机无提示识别 | 动态范围低于12dB即进入无提示识别复核；检查结果不等于主观音质或人物身份验收 |
| 声学异常且识别与目标明显不符 | 只为异常组以完整原句、同人物参考和正式 Torch25 FP32 重生成 | 原文和批准译文保持；同源组仅一次，失败停止，原 WAV 与旧交付保留 |
| 编码后响度有限数值越界 | 对完整混音做两遍响度处理，以128k AAC重新封装并复制已压缩画面 | 不重做翻译、配音、字幕或画面编码；核视频包、PCM帧数、实际AAC和完整媒体 |
| 字幕长句 | 配音前用渲染器同一排版函数检查，有限调整中文30–34与源文20–24字号 | 原文字与时间不变，中文最多3行、源文最多5行；放不下则停止 |
| 配音较原画面长 | 明确允许后逐组检查实际末帧，必要时避开空白转场，最多停格4秒 | 声音完整、不加速；许可绑定来源、成员、音频 SHA 与画面证据 |
| 画面超过4秒或无可靠末帧 | 压短可压缩译文，或在网页核对 | 不自动扩大时长上限、不跳过画面检查 |
| 空间不足 | 核验当前原片、阶段签名和正式输出 SHA 后扣除可复用阶段，必要时清理本任务两项背景临时文件，再实测空间 | 默认8GiB余量和运行2GiB底线保持；原片、原始WAV、分离轨、母带及旧交付保留 |
| 服务中断 | 保留原编号及断点，网页继续 | 不能把未校验文件标为最终完成 |

## 限额与留痕

- 文字恢复最多6次动作，每次最多8行、编辑与独立审校各一次；仍有真实内容拒绝时可在当前调用内再尝试一次，同输入总计最多两次。预算在调用前持久化，关闭服务或反复点击不会退款或清空。
- 媒体恢复另有6次固定数据动作预算；单次流水线最多6轮局部续跑，整个运行及分集共用4小时时间预算。
- 成功动作幂等复用；失败保留具体原因及原始文件。两份恢复日志、源文修订和 SHA 证据仅保存在本机任务目录，不提交到 Git。
- 中断的文字事务只在输入仍匹配时继续提交已验证结果；网页“继续”会先恢复未完成的人工保存，再检查修订和排队。不会用陈旧提示覆盖新的人工修改。
- 文字恢复预算用完后不会继续自动请求；已有声音、字幕和媒体阶段可按各自预算继续。用户可在网页核对并保存新内容，再通过普通继续入口完成余下步骤；预算不会因此重置。
- 未知错误、依赖缺失、证据损坏、无法保留事实的改写会明确停止。Proxy 无任意文件、代码、命令或全局配置修改权限。

## 导出与缓存

全部原句、完整意群音频和逐句字幕必须覆盖一次；字幕仍按真实配音定位。画面在烧字幕前按帧序号统一25fps时钟，避免片段容器尾部偏移累积。最终视频严格小于50,000,000字节，必要时两遍压缩并保持音频包，随后重新执行帧数、时间轴、音轨、峰值和全解码检查。

归档使用经过完整校验的明确交付清单，复制前后核对SHA；不递归复制任务缓存。归档再次运行时复用同一版本，不同版本另存，不能覆盖旧交付。明确续跑已完成任务以修订缺陷时，保留原completed历史和旧归档。

提示、源文修订、局部排组及画面许可均参与对应缓存身份。无关编排代码变动不再自动使说话人或背景阶段失效；旧缓存迁移必须先精确复算旧签名、确认阶段实现未变，并验证全部输出 SHA。

## 配置与验证

沿用本机私有 `config/web_proxy.json`，不新增或提交凭证；上传视频、原声、模型和私有任务记录均不入库。源码仓库中的空示例及固定模型/子模块版本维持原约定。

部署与测试的实际结果以本轮发布记录为准。短探针、合成失败测试和机器工程检查不构成所有来源的无人值守成功率承诺，也不替代完整试听。
