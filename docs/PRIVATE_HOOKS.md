# 公开构建的专项边界

公开源码保存通用生产流程，不携带实际素材的任务注册、原文、翻译、人物声音、用户答复、授权范围、媒体校验值或历史收据。部分带日期的模块名仍保留，仅用于维持通用代码的导入接口，不表示对应专项功能已向新任务开放。

`portable_private_hooks.py` 只读检查当前任务的专项凭据。普通任务没有这些凭据时，查询接口返回空注册、未解除的状态或原始manifest路径，继续正常翻译、终审、声音核对、字幕与导出。普通配音必须精确匹配显示文字及计划中的有效读法。适配器不能生成批准、解除旧拒绝、接纳未知声音或增加恢复额度。

发现上下文采纳、单期编辑决定、冻结批准包、额外有界续办、专项声音选择或生成失败组合的凭据时，公开构建明确报错。直接调用专项生成、提交、注册、验证或模块命令行入口也会拒绝；不会把存在的私人凭据当作缺省空值忽略。要移植私有历史任务，应单独审阅并安装其完整本地集成，不能仅复制某份收据或放宽检查。

早期已有的画面hold、单句声音修正及专项时序复核仍使用 `config/source_scopes.local.json` 的原有严格验证器；空示例没有注册。其他注册键由公开构建拒绝。注册本身从不替代真实授权、完整来源、媒体身份和独立审批。

默认归档余量保持8GiB。已授权的单期资源例外、额外恢复动作、固定译文和读音风险选择均不随源码发布，也不会迁移到普通新任务。通用正式Torch回退、完整声音检查和有界服务接管保持独立工作。

每日节目发现工具可以读取公开节目资料；自动领取、账号连接器、完成邮件和每日自动化状态属于各自部署层。本源码同步未打包这些账户或历史状态。
